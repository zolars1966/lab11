### Задание 8.

Исходная программа:

```cpp
#include <iostream>

int main() {
    int *p = new int[10];
    int *q = new int[10];
    for (int i = 0; i <= 10; i++)
        p[i] = i;
    q = p;
    delete[] p;
    for (int i = 0; i <= 10; i++)
        std::cout << q[i] << " ";
    delete[] q;
    return 0;
}
```

Исходная программа выделяет два массива, но затем присваивает `q = p`. После этого адрес второго массива теряется, а значит, освободить его уже нельзя. Это **утечка памяти**.

Далее `delete[] p` освобождает первый массив. Указатель `q` содержит тот же адрес, поэтому он становится висячим. Чтение `q[i]` после освобождения — **обращение к памяти после её освобождения**, то есть неопределённое поведение.

Кроме того, оба цикла используют условие `i <= 10`, хотя массив содержит только 10 элементов с индексами от 0 до 9. Обращение к `p[10]` уже в первом цикле — **выход за границы массива**. После этого поведение программы не определено.

Наконец, `delete[] q` пытается повторно освободить уже освобождённый массив — это **повторное освобождение памяти** и также неопределённое поведение.

### Задание 1.

`decltype(foo)` — это тип функции `int(int)`. Поэтому `decltype(foo)*` — указатель на функцию, принимающую `int` и возвращающую `int`.

В исходном варианте `bar` имеет тип `double(double)`. Указатель на функцию с типом `int(int)` нельзя присвоить адресу функции с другой сигнатурой: типы параметров и возвращаемого значения не совпадают.

Замена типа `double` на `int` только в объявлении результата функции `bar` не решает проблему полностью: параметр `bar` тоже должен быть `int`, иначе тип функции останется `int(double)` и не совпадёт с `int(int)`.

Исправление:

```cpp
#include <iostream>

int foo(int x) { return x + 1; }
int bar(int x) { return x - 1; }

int main() {
    decltype(foo)* pf = bar;
    std::cout << pf(0);
    return 0;
}
```

**Результат:** `-1`.

### Задание 2.

Правило сортировки: сначала целая часть по возрастанию, при равенстве целых частей — дробная часть по убыванию. Дробную часть вычисляем как `x - floor(x)`. Для заданного примера порядок будет таким: `1.9; 1.32; 1.0; 5.8; 5.1; 12.6; 13.2; 13.1`.

#### C++

```cpp
#include <algorithm>
#include <cmath>
#include <iostream>
#include <vector>

int main() {
    std::vector<double> a{13.1, 1.32, 5.1, 12.6, 1.0, 13.2, 1.9, 5.8};

    std::sort(a.begin(), a.end(), [](double x, double y) {
        double ix = std::floor(x), iy = std::floor(y);
        if (ix != iy) return ix < iy;
        return (x - ix) > (y - iy);
    });

    for (double x : a) std::cout << x << ' ';
    std::cout << '\n';

    return 0;
}
```

#### Java

```java
import java.util.Arrays;

public class Main {
    public static void main(String[] args) {
        Double[] a = {13.1, 1.32, 5.1, 12.6, 1.0, 13.2, 1.9, 5.8};

        Arrays.sort(a, (x, y) -> {
            int byInteger = Double.compare(Math.floor(x), Math.floor(y));
            if (byInteger != 0) return byInteger;
            return Double.compare(y - Math.floor(y), x - Math.floor(x));
        });

        System.out.println(Arrays.toString(a));
    }
}
```

#### Python

```python

numbers.sort(key=lambda x: (math.floor(x), -(x - math.floor(x))))

```

### Задание 4.

Каждая строка треугольника содержит ровно столько элементов, сколько нужно: в строке `i` — `i + 1` элементов. Поэтому выделяем массив указателей на строки, а затем для каждой строки отдельно выделяем массив нужной длины.

```cpp
#include <iostream>

int main() {
    int n;
    std::cout << "Введите количество строк: ";
    std::cin >> n;

    if (!std::cin || n < 0) {
        std::cerr << "Некорректный размер\n";
        return 1;
    }

    int** pascal = new int*[n];

    for (int i = 0; i < n; ++i) {
        pascal[i] = new int[i + 1];
        pascal[i][0] = 1;
        pascal[i][i] = 1;

        for (int j = 1; j < i; ++j)
            pascal[i][j] = pascal[i - 1][j - 1] + pascal[i - 1][j];
    }

    for (int i = 0; i < n; ++i) {
        for (int j = 0; j <= i; ++j)
            std::cout << pascal[i][j] << ' ';
        std::cout << '\n';
    }

    for (int i = 0; i < n; ++i)
        delete[] pascal[i];
    delete[] pascal;

    return 0;
}
```

Например, для `n = 5` программа выведет:

```
1
1 1
1 2 1
1 3 3 1
1 4 6 4 1
```

Память не расходуется на отсутствующие элементы прямоугольной таблицы: для каждой строки выделяется только `i + 1` целых чисел. Сначала освобождаются все строки, затем массив указателей.
